This is exercised through actual mid-route replanning from `STAIRS1-G` and `LIFT3-F2`, plus the saved frontend regression tests.

Changes are in `frontend/app.js`; `frontend/index.html` versions the script URL to refresh cached clients. `frontend/dev_server.py` adds an optional same-origin development proxy, documented in `frontend/README.txt`. The backend and database were not modified.
